# 60–90 Second Demo Script

1. Open the app at `http://127.0.0.1:8000/ui`.
2. Stay on the seeded interview view and point out the session metadata bar: Session ID, Current Stage, Prompt Version, Last Updated, Clarifications Used, Decision Source, and Fallback Activated.
3. Show the first seeded session in a clarification state and highlight the weak recorded answer in the transcript.
4. Point to the evaluation summary and explain that the workflow paused because the answer lacked enough evidence to advance.
5. Send or reveal the stronger follow-up answer and show that the system advances to the next stage instead of staying in clarification.
6. Call out the updated stage and the persisted prompt version surface on the right-hand side.
7. Switch to the Review Console and open the review trace so the viewer can see the answer, evaluation summary, missing evidence, action taken, and state transition for each interaction.
8. Finish on the Prompt Governance tab to show the active prompt version, version history, and the collapsed full prompt definition.
